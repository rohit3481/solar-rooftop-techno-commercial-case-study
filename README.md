# Solar Rooftop PV | Techno-Commercial Case Study

## Overview

A self-directed techno-commercial case study for a residential
grid-connected rooftop solar PV system. The project combines
technical system sizing, component selection, BOM development,
cost estimation, subsidy assessment and customer payback analysis.

## Customer Scenario

- Location: Delhi-NCR representative residential case
- Monthly electricity bill: ₹5,500
- Assumed tariff: ₹8/kWh
- Annual consumption: ~8,250 kWh
- Roof area: 550–600 sq ft
- Target: Reduce electricity cost while maintaining a practical
  upfront investment

## Proposed System

- System size: 5.175 kWp
- Solar modules: 9 × 575 Wp Waaree bifacial modules
- Inverter: Loom Solar Fusion 63, 6 kW, 3-phase
- Estimated Year-1 generation: ~6,800 kWh

## Techno-Commercial Analysis

The case study includes:

- Load assessment and system sizing
- Solar module and inverter selection
- Bill of Materials (BOM)
- Project costing
- EPC overhead and commercial margin
- PM Surya Ghar subsidy assessment
- Customer savings and payback analysis
- Sensitivity analysis for tariff, generation and project cost

## Key Results

| Metric | Value |
|---|---:|
| System Size | 5.175 kWp |
| Year-1 Generation | ~6,800 kWh |
| Gross Project Price | ₹2.78 lakh |
| PM Surya Ghar CFA | ₹78,000 |
| Net Customer Investment | ~₹2.00 lakh |
| Year-1 Net Savings | ~₹47,310 |
| Simple Payback | ~4.23 years |
